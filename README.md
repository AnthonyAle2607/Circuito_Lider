# Sistema de Pautas Comerciales

Plataforma de Invermedia para vender espacios de radio en Circuito Líder a anunciantes del exterior.

## Arrancar

Requisitos: Node 22 o superior, pnpm 9 (`corepack enable`) y Docker.

```bash
pnpm install
pnpm iniciar
```

Abre el portal en http://localhost:3100 y el panel en http://localhost:3110. La guía completa del repositorio está en `CLAUDE.md`.
